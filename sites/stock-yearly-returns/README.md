# 股票年度報酬率

輸入股票代號及投入日期，查看投入後每個曆年的歷史報酬率。

網站：https://stock-yearly-returns.ts701105.chatgpt.site/

`docs/` 是供 GitHub Pages 使用的靜態前端。它會向上述網站的 `/api/returns` 查詢歷史股價；GitHub Pages 本身不執行伺服器程式，因此該資料 API 必須可公開存取，試算功能才能運作。

## 使用方式

- 台股上市股票可直接輸入代號，例如 `2330`；上櫃股票可輸入完整代號，例如 `6488.TWO`。
- 美股可輸入代號，例如 `AAPL`。
- 輸入投入日期後，按「計算報酬率」。非交易日會從下一個交易日開始計算。

## 計算方式

網站透過伺服器查詢 Yahoo Finance 的每日調整後收盤價。投入當年以投入日後首個交易日為期初，其後各年以前一年度最後交易日為期初，並以該年最後交易日為期末。今年計至最新可用交易日。

年度報酬率 = 期末調整後收盤價 ÷ 期初調整後收盤價 − 1。調整後價格通常反映拆股與現金股利；結果不含交易費、稅、匯率變動及個人實際股利再投入差異。資料僅供歷史試算。Yahoo Finance 的資料可用性與更新時間可能變動。

## 本機執行

需要 Node.js 22.13 以上與 pnpm。

```bash
pnpm install
pnpm dev
```

開啟終端機顯示的本機網址。建置可執行 `pnpm build`。
